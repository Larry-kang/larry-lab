# Larry Lab

公開的個人財金試算與工具網站：把假設算清楚，再做決定。

正式網站：<https://larry-lab.pages.dev/>

2026-10-21 操作體驗更新已正式發布：金額千分位、精確年月切換、模式摘要與方案鍵盤操作。版本、測試及部署限制見 [本輪驗收紀錄](docs/TOOL_UX_VALIDATION.md)。

Larry Lab 為台灣使用者提供房貸、信貸、股票質押、退休及投資組合五大財金試算器，並整理數位銀行、證券開戶與加密資產服務推薦資訊。所有試算皆在瀏覽器本機執行，不設伺服器端個人資料庫，亦不載入第三方追蹤腳本。

---

## 五大財金試算器

1. **房貸試算器 (`/tools/mortgage/`)**
   支援房價頭期款、貸款成數或直接本金模式，涵蓋本息與本金均攤、固定與多段利率、寬限期、開辦手續費、每月所得負擔比（DTI）、多方案並排比較與每月攤還表 CSV 下載。
2. **信貸試算器 (`/tools/personal-loan/`)**
   計算每月還款金額、總利息支出、扣除開辦費後的期初實拿金額與估算有效年化成本（IRR），支援多方案比較與攤還明細 CSV 下載。
3. **股票質押試算器 (`/tools/stock-pledge/`)**
   計算擔保品市值、借款金額與綜合維持率，推算觸及追繳（如 130%）與回補目標（如 166%）之跌幅門檻，並同時列出「現金還款」與「追加合格擔保品」兩種改善方案。
4. **退休試算器 (`/tools/retirement/`)**
   依今日物價與預估通膨率，推算目標退休所需本金、每月應存金額與最早可退休年齡，支援工作期／退休期不同報酬率、其他退休月收入折抵，以及「今天購買力／未來名目金額」切換。
5. **投資組合試算器 (`/tools/portfolio/`)**
   - **配置與壓力測試模式**：檢視各類資產權重、負債槓桿與自訂市場漲跌情境下的淨值變動。
   - **長期資產累積模式**：推估定期定額投入與每年定期再平衡之長期資產走勢（目標權重總和須嚴格等於 100%）。

## 產品設計特色

- **極簡科技實驗室品牌視覺**：採用「Geometric L」幾何實驗室標誌與青綠中性配色，提供清晰易讀的等寬數值排版（`tabular-nums`）。
- **目的導引與同義詞搜尋**：首頁與工具大全提供直覺問句入口與關鍵字同義詞篩選（如「購屋／頭期款」、「FIRE／財務自由」、「維持率／追繳」、「再平衡／配置」）。
- **基本與進階設定分流**：常用參數直接呈現於基本設定，分段利率、寬限期、手續費與通膨率收折於進階設定，保持畫面清爽且折疊不遺失數值。
- **多方案並排比較與條件同步**：支援複製方案、動態利率／報酬徽章、基準條件差異提醒與一鍵同步基本條件。
- **本機儲存與匯出備份**：支援 CSV 試算明細下載、JSON 設定檔匯出／匯入，以及選用的瀏覽器 LocalStorage 本機記憶功能（附 8 秒復原重設機制）。
- **常用金融與加密服務推薦**：集中整理 18 項數位銀行、證券開戶、台灣交易所、國際交易所與其他加密服務之官方推薦連結與邀請碼，附官方品牌圖示與單鍵複製功能。

## 本機開發與驗證指令

環境需求：Node.js `>= 22.12.0`

```bash
# 安裝依賴套件
npm ci

# 啟動本機開發伺服器
npm run dev

# 執行 Astro 型別與模板檢查
npm run check

# 執行 ESLint 程式碼規範檢查
npm run lint

# 執行單元測試
npm test

# 建置靜態網站（輸出至 dist/）
npm run build

# 執行 Playwright 端對端瀏覽器測試
npm run test:e2e
```
