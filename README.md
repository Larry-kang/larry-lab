# Larry Lab

公開的個人工具大全網站：把假設算清楚，再做決定。

Larry Lab 專為台灣使用者打造，提供房貸、信貸、股票質押、退休及投資組合五大實用財金試算器。所有計算完全在瀏覽器本機記憶體完成，無後端伺服器儲存、零追蹤腳本，絕不串接或讀取任何外部金融帳戶，確保個人資料最高隱私。

---

## 核心特色與第二版更新

### 1. 簡潔原創的青綠中性視覺與排版
- 全站採簡潔、原創的青綠（teal/sage）與中性色系，近白底、深灰文字。
- 每頁僅單一主要操作使用實心主色（「查看試算結果」按鈕），減少視覺雜訊。
- 數字全面採用等寬字型（`tabular-nums`），金額單位清楚標示。
- 嚴格落實首屏可見性：手機螢幕（360x800, 390x844）首屏確保標題、用途與第一個基本輸入欄位清晰可見；桌機螢幕（1440x900）首屏確保基本欄位與核心指標卡片可見。

### 2. 目的導引與首頁工具搜尋
- **目的入口問句**：提供直覺問句入口（「買房月付多少？」、「借款成本差多少？」、「質押跌多少要注意？」、「還要存多少才能退休？」、「配置改變會有什麼影響？」）直接跳轉。
- **純本地同義詞搜尋**：支援關鍵字與生活用語比對（如「購屋/頭期款」、「FIRE/財務自由」、「維持率/追繳」、「再平衡/配置」），提供結果筆數提示、清除按鈕與零結果友善狀態，搜尋字詞純在記憶體中比對，不外傳伺服器。
- **工具大全分類**：提供「全部 / 買房與借貸 / 投資與退休」分類標籤與搜尋聯合篩選。

### 3. 基本／進階設定與三項核心重點結果
- **輸入分流**：最常用之核心參數列於「基本設定」；進階條件（分段利率、寬限期、手續費、通膨率、年金收入等）收折於「進階設定」，按鈕旁顯示即時摘要，折疊不遺失數值，有驗證錯誤時自動展開。
- **自動重算與平滑導覽**：輸入有效數值時具備 250ms 防抖自動重算；點擊「查看試算結果」平滑捲動至結論區。
- **三項核心重點卡片**：醒目呈現最關鍵的 3 個決策數據，輔以次要指標、圖表及等值明細數據表格。若輸入無效，原結果立即標示「輸入待修正，以下結果已失效」，防止誤用舊數據。

### 4. 改善情境比較與條件同步契約
- **動態情境徽章**：方案標籤依據實際輸入之利率或報酬動態產生（如「年利率 2.2%」、「年報酬 5%」），杜絕修改後名稱仍殘留寫死文字之問題。
- **深複製與基本條件同步**：新增方案深複製當前情境；提供「以方案 A 的基本條件套用至其他方案」按鈕，在保留各方案比較變數（利率/報酬）的前提下同步基準條件。
- **基準差異提示**：比較表自動偵測各方案之本金、年齡或月收支差異，並醒目提示「基本條件不同」警示。

### 5. 儲存與設定管理（收合於頁面底部）
- 相關管理操作移至頁面底部 details 收合區，不干擾初次輸入。
- 包含：載入示範範例、清空重設（附 8 秒 Undo 復原機制）、JSON 參數備份匯入與匯出、複製工具純網址（不夾帶金額參數）。
- **LocalStorage 儲存澄清**：若主動勾選記住設定，資料以**未經加密的純文字 JSON 格式**存放於本機瀏覽器 LocalStorage。明確提醒共用裝置切勿使用，並提供單鍵刪除功能。

### 6. 安全標頭與 Cloudflare Pages 整合
- 根目錄 `public/_headers` 提供嚴格安全標頭（`CSP`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`），Astro 建置產物完整輸出至 `dist/_headers`。
- 本機預覽測試伺服器解析 `dist/_headers` 規則套用，確保開發環境與雲端部署行為一致。

## 五大財金試算器

1. **房貸試算器 (`/tools/mortgage/`)**：
   支援房價頭期款/本金模式、本息與本金均攤、固定與多段利率、寬限期、期初開辦手續費、每月所得負擔比 (DTI)、方案比較與每月攤還表 CSV 下載。
2. **信貸試算器 (`/tools/personal-loan/`)**：
   計算每月還款金額、總利息、開辦費扣除後實拿金額、現金流有效年化成本 (IRR)、方案比較與每月攤還表 CSV 下載。
3. **股票質押試算器 (`/tools/stock-pledge/`)**：
   支援擔保品市值與借款計算、綜合維持率追蹤、補繳（130%）與斷頭（140%/166%）跌幅門檻；清楚區分「現金還款」與「追加擔保品」兩種解法，支援零借款無負債安全邊界。
4. **退休試算器 (`/tools/retirement/`)**：
   預設單一情境 A，提供「載入三組報酬範例（5%、7%、10%）」；依今日物價與通膨率推算目標退休所需本金、每月應存金額、最早可退休年齡、其他年金收入折現，支援名目與實質購買力切換。
5. **投資組合試算器 (`/tools/portfolio/`)**：
   - 配置與壓力測試模式：資產市值與自訂漲跌幅、負債槓桿倍數、壓力後淨值變動。
   - 長期資產累積模式：定期定額每月投入與每年定期再平衡走勢推估。**目標權重總和相加須恰等於 100%**，不足或超額時嚴格提示拒絕，系統不會擅自為你自動等比例修改權重。

## 技術架構與執行環境

- **框架**：[Astro 7](https://astro.build/) (純靜態 SSG 輸出，適合 Cloudflare Pages 全球 CDN)
- **執行環境**：Node.js `>= 22.12.0`（本機驗證環境：Node.js `v24.11.1`）
- **語言**：TypeScript (純函數計算核心，明確邊界與型別定義)
- **樣式**：原生現代 CSS（Custom Properties、Grid、Flexbox，極輕量載入無 Runtime 負擔）
- **測試**：
  - [Vitest](https://vitest.dev/)：111 項單元測試，包含獨立數學推導比對 `docs/CALCULATION_CONTRACT.md`（殘差 <= 0.01 元）。
  - [Playwright](https://playwright.dev/)：56 項端對端整合測試，涵蓋 Desktop (1440x900) 與 Mobile (360x740) 完整操作流程。
- **代碼規範**：ESLint (flat config) 與 Astro Check。

## 開發與驗證指令

```bash
# 1. 安裝依賴套件
npm ci

# 2. 啟動本機開發伺服器
npm run dev

# 3. 執行 Astro 型別與模板檢查
npm run check

# 4. 執行 ESLint 語法與代碼規範檢查
npm run lint

# 5. 執行計算核心與獨立推導單元測試
npm test

# 6. 靜態建置輸出 (產物與 _headers 存於 dist/)
npm run build

# 7. 執行端對端 (E2E) 瀏覽器測試
npm run test:e2e
```
