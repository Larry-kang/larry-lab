# 房貸回訪功能

- R01：兩個固定虛構範例可從指南進入工具，網址只含範例代號。
- R02：明確按下儲存才更新房貸快照，包含目前比較的所有方案；可載入及清除。保留既有進階記住設定。
- R03：兩篇指南、首頁入口、工具互鏈與 sitemap 一起建置。公式維持原樣。
- R04：透過型別、單元、建置與桌機／手機瀏覽器測試驗收；Search Console 擁有權另在正式站確認。

本機驗收：159 項單元測試通過；靜態建置與 24 筆 sitemap 檢查通過。初次完整瀏覽器測試發現桌機首屏回歸，調整位置後，桌機及手機的首屏與房貸快照 4 項針對性重測均通過。Search Console 尚未驗證或送出 sitemap。
