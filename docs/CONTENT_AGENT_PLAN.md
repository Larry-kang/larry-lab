## 設計與驗收

- [x] G01：新增「教學指南」入口與 ether.fi 系列，九篇依基礎到進階排序。全部為官方資料整理與教育內容，不冒稱親身心得；沒有帳戶／操作實測，不提供即時費率或台灣資格保證。
- [x] G02：文章具摘要、閱讀前提、目錄、來源、查核日期、前後篇與集中管理的推薦連結。保留既有共用版面與手機推薦區。
- [x] G03：HTML、Markdown、公開 JSON 目錄、Article JSON-LD、sitemap、llms.txt 皆由同一份文章資料生成。草稿不產生公開路由；無 JavaScript 仍可閱讀。
- [x] G04：於儲存庫提供 agent 使用說明，公開畫面不顯示 Agent／Markdown 技術入口，明確區分可讀內容與可呼叫計算工具；研究遠端 MCP 架構、免費額度、安全、隱私與驗證方式。本次不新增動態 MCP 後端或宣稱已提供遠端工具。
- [x] G05：型別、lint、單元、建置同步檢查與桌機／360px 瀏覽器測試。檢查所有文章與 Markdown 內容一致、無橫向溢出、來源與推薦連結明確區分。

## 實作順序

1. 先寫內容模型／輸出測試並確認失敗，再建立文章資料與驗證函式。
2. 建立列表、系列、文章與 Markdown 路由；串接導覽、首頁與推薦總覽。
3. 延伸現有 SEO 生成與產物檢查，加入 JSON 內容目錄與 agent 說明。
4. 完成 MCP 研究與維護文件，執行必要檢查、修正並記錄結果。
