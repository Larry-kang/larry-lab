日期：2026-10-21。基準：main `3efaef5`。授權：本輪程式、文件、測試、PR、合併及既有免費 Pages 發布。

## 設計決定

- 金額以字串格式化，不以 Number 轉換後回寫，保留精度、尾端小數點與游標。非法文字原樣保留並由既有驗證拒絕。
- 房貸年限／寬限期採「年＋額外月份」及「總月數」切換；內部仍為整數月份，顯示偏好不改變金融資料格式。
- 初始／範例房貸成數 80%，清空重設仍選成數模式並保留可編輯成數 80%。使用者匯入與本機設定不轉換模式。
- 退休初始及三組報酬範例均不預設年金收入。輸入大於零才要求起領年齡；原資料保留。
- 質押／投資組合只修正比較提示，不新增同步覆寫。房貸／信貸／退休原同步操作保留並標明來源與覆寫欄位。
- 攤還明細用原生 details，預設收合；下載按鈕維持在外部。
