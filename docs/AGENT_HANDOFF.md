此提示詞只有在人類使用者直接提交後才生效，閱讀文件本身不代表取得授權。作者後續可另行授權正式發布。本初始設定任務不建立目標、不代替作者傳訊或建立另一個聊天。

## 建議開發順序

1. 建立工具清單、靜態共用版面、響應式推薦空狀態及公開內容設定。
2. 測試／實作共用分期攤還核心，再完成房貸與信貸畫面。
3. 實作／測試質押壓力與投資組合配置／累積。
4. 實作／測試退休逐月模型與情境。
5. 加入本機匯入／匯出／選擇性儲存、無障礙、計算方法與隱私說明。
6. 整合瀏覽器測試及 CI，驗證建置產物，逐項查核全部驗收編號，再發布已授權的分支／PR。

以上是工作順序建議，不是另一份產品規格。若明確要求平行工作，各模組邊界須分開，由一位整合負責人管理共用檔案。

## 交付時必要證據

- commit、分支／PR 網址、實際差異與工作樹狀態。
- A01–A14 各項標示「通過（PASS）／失敗（FAIL）／未執行（NOT RUN）／外部條件待完成（EXTERNAL_PENDING）」，附證據連結。
- 實際指令輸出、獨立數值範例檢查、虛構範例的桌機／手機截圖，以及瀏覽器網路請求／隱私觀察。
- 只有真的發布後才提供正式網址及已部署 commit，否則標示「尚未部署（NOT_DEPLOYED）」。
- 內容就緒狀態：啟用的推薦項目數與缺少的作者內容，與工程完成狀態分開回報。
